## Top picks
### 1. [Tracking AI adoption in North Korean threat actor tradecraft](https://www.microsoft.com/en-us/security/blog/2026/10/29/tracking-ai-adoption-in-north-korean-threat-actor-tradecraft/)
**Microsoft Threat Intelligence · Oct 29, 2026**
Microsoft reports how several North Korean groups use AI for reconnaissance, persona and lure creation (fake resumes, profile images, synthetic voice and video), malware and tooling development, and scaling routine operations. It rates Jade Sleet, Coral Sleet and Jasper Sleet as having operationalized AI, others as accelerating or expanding. It stresses that operations remain human-directed rather than autonomous.
**Methodology:** Vendor threat-intelligence report based on observed activity (e.g. file metadata showing 100+ PDF lures made within minutes); the adoption-stage ratings are Microsoft's own assessment.
**Why it matters:** It is a grounded counterweight to claims of autonomous offensive agents, useful for calibrating the threat model in offensive-agent work.

### 2. [Inside a malicious Claude Code-branded extension and its persistent SSH backdoor](https://www.microsoft.com/en-us/security/blog/2026/10/30/inside-malicious-claude-code-branded-cursor-extension-persistent-ssh-backdoor/)
**Microsoft Security (authors not listed in the content I could read) · Oct 30, 2026**
Analysis of a fake Claude Code extension for Cursor that installs a persistent SSH backdoor, with detection and remediation guidance. I only read the index summary, not the full post.
**Methodology:** Malware and incident analysis with detection guidance.
**Why it matters:** Another case of AI coding-tool supply chain attacks, following last week's LiteLLM compromise, and relevant to the security of AI-assisted SE environments.

### 3. [How AI agents shape experts' judgment calls](https://www.anthropic.com/research/agents-judgment-calls)
**Anthropic Alignment · Oct 27, 2026**
In a test with 50 professional analysts using Claude Code, analysts mostly followed the agent's randomly assigned choice among defensible options, and few named the agent as a reason afterward. I read only the index summary.
**Methodology:** Randomized human-subject study assigning agent choices among defensible options.
**Why it matters:** It is not security-specific, but it suggests developers may defer to agent-chosen fixes or design choices, which bears on the security of AI-assisted code.
